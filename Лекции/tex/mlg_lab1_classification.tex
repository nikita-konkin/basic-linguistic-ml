\begin{frame}{Базовый уровень качества}
\color{ink}
{\small Базовое решение всегда выбирает один, самый частый класс. При четырёх равных классах оно даёт accuracy = 0,250.
\par\vspace{0.6em}На реальном проекте распределение может быть другим. Базовое качество нужно вычислять заново.}
\врезка{Если 90 \% сегментов относятся к одному классу, постоянный ответ этим классом даст 0,90. Такая оценка ещё не означает полезного распознавания остальных классов.}
\end{frame}

\begin{frame}{Токенизация}
\color{ink}
{\small Токенизация — разбиение текста на единицы по заданным правилам. Для словесной модели результатом обычно служат слова и, при необходимости, отдельные знаки.
\par\vspace{0.6em}В локализации важно заранее решить, как обрабатывать дефисы, числа, теги и подстановочные поля.}
\врезка{\texttt{\{name\}} — подстановочное поле: при работе программы его заменяют значением. Скобки и имя поля нужно сохранить в переводе.}
\end{frame}

\begin{frame}{TF-IDF: частота в сегменте и редкость в корпусе}
\color{ink}
{\small \[\displaystyle w(t,d)=\mathrm{tf}(t,d)\left(\ln\frac{1+N}{1+\mathrm{df}(t)}+1\right)\]
\par\vspace{0.6em}$\mathrm{tf}(t,d)$ — число вхождений слова в сегмент, $\mathrm{df}(t)$ — число сегментов со словом, $N$ — число обучающих сегментов. Затем вектор нормируют.}
\врезка{Частые во всём корпусе слова получают меньший IDF. Их языковая или переводческая важность этим не определяется.}
\end{frame}

\begin{frame}{Какие слова получают большой вес}
\color{ink}
\centering\includegraphics[width=.80\textwidth,height=4.05cm,keepaspectratio]{fig/tad_idf.pdf}\par\raggedright{\small Слева показана зависимость IDF от частоты по документам; справа — пример распределения весов внутри сегмента.}
\врезка{Частица «не» может иметь небольшой вес и при этом полностью менять смысл сообщения.}
\end{frame}

\begin{frame}{Наивный байесовский классификатор}
\color{ink}
{\small Модель оценивает вероятность класса по признакам. «Наивное» предположение состоит в условной независимости признаков при известном классе.}
\[P(y\mid\mathbf x)\propto P(y)P(\mathbf x\mid y)\]
{\small В мультиномиальном варианте признаки описываются частотами. В лабораторной используется MultinomialNB с неотрицательными TF-IDF-признаками.}
\врезка{Соседние n-граммы связаны, поэтому предположение независимости приблизительно. Полезность модели определяется проверкой на новых сегментах.}
\end{frame}
\begin{frame}{Логистическая регрессия для классификации}
\color{ink}
{\small Для каждого класса модель вычисляет линейную оценку признаков. В многоклассовом варианте softmax преобразует оценки в вероятности.}
\[z_k=\mathbf w_k\cdot\mathbf x+b_k,\qquad p_k=\frac{e^{z_k}}{\sum_m e^{z_m}}\]
{\small Предсказание — класс с наибольшей вероятностью. Веса подбирают по размеченным обучающим примерам. Несмотря на название, модель здесь решает задачу классификации.}
\врезка{Подробный разбор softmax, потерь и градиента дан в блоке 2 лекции «Текст как данные».}
\end{frame}

\begin{frame}{Первый результат и неопределённость}
\color{ink}
{\small TF-IDF по словам и наивный байесовский классификатор: средняя accuracy — 0,444; стандартное отклонение по пяти разбиениям — 0,085.
\par\vspace{0.6em}Стандартное отклонение описывает разброс результатов между разбиениями. Оно не является доверительным интервалом для разницы двух моделей.}
\врезка{Разницу в несколько сотых нужно рассматривать на одинаковых разбиениях и сопоставлять с конкретными исправленными ошибками.}
\end{frame}

\begin{frame}{Стемминг и лемматизация}
\color{ink}
\begin{columns}[T,onlytextwidth]\column{0.47\textwidth}{\small \textbf{Стемминг} сокращает словоформу по правилам до общей последовательности символов. Результат не обязательно совпадает с лингвистической основой.
\par\vspace{0.6em}Например, разные формы слова могут получить общий фрагмент «изменен».}
\column{0.47\textwidth}{\small \textbf{Лемматизация} приводит словоформу к словарной форме. Для омонимичных форм может потребоваться контекст.
\par\vspace{0.6em}«Стали» может относиться к лемме «стать» или «сталь».}\end{columns}
\end{frame}

\begin{frame}{Что изменилось после стемминга}
\color{ink}
{\small Число признаков сократилось с 679 до 555. Средняя accuracy выросла с 0,444 до 0,538; стандартное отклонение стало 0,135.
\par\vspace{0.6em}Вероятное объяснение: разные формы стали общими признаками. Его проверяют на сегментах, предсказания для которых изменились.}
\врезка{Стемминг может также объединить разные слова. Рост среднего в одном опыте не гарантирует улучшения на другом корпусе.}
\end{frame}

\begin{frame}{Символьные n-граммы}
\color{ink}
{\small Символьная n-грамма — последовательность из n соседних символов. В качестве признаков используют, например, фрагменты длиной от 2 до 4.
\par\vspace{0.6em}«сохранить»: \texttt{сох}, \texttt{охр}, \texttt{хра}, \texttt{ран}, \texttt{ани}, \texttt{нит}, \texttt{ить}. Часть фрагментов совпадает с «сохранение».}
\врезка{Общие фрагменты позволяют связать словоформы без морфологического словаря. Фрагмент может также пересекать границу морфемы или слова.}
\end{frame}

\begin{frame}{Сравнение моделей}
\color{ink}
{\small При фиксированных символьных n-граммах 2–4 логистическая регрессия в лабораторной достигает средней accuracy 0,744. Наивный байесовский классификатор с теми же признаками даёт 0,612.
\par\vspace{0.6em}Сначала сравнивают признаки при одной модели, затем модели при фиксированных признаках. Так можно объяснить источник изменения качества.}
\врезка{Из одного опыта нельзя вывести, что признаки всегда важнее алгоритма. Вклад зависит от корпуса, задачи и исходной конфигурации.}
\end{frame}

\begin{frame}{Почему словесные признаки теряют короткие строки}
\color{ink}
{\small В контрольной части может оказаться сегмент, у которого ни одно слово не встречалось в обучающей. Его словесный вектор окажется нулевым.
\par\vspace{0.6em}В опыте курса таких сегментов 44 из 160. При символьных n-граммах пустых векторов в этих разбиениях нет.}
\врезка{Общие части слов повышают покрытие. Это не означает, что модель автоматически распознаёт морфемы и их функции.}
\end{frame}

\врезка{Большой вклад показывает связь в модели. Чтобы назвать её грамматической закономерностью, нужны контексты и проверка на новых данных.}

\begin{frame}{Как избежать утечки данных}
\color{ink}
{\small Не вычислять словарь и IDF по всему корпусу до кросс-валидации. Не подбирать настройки по окончательной тестовой выборке.
\par\vspace{0.6em}Проверить близкие дубликаты. Если сегменты относятся к одному документу или шаблону, использовать групповое разбиение при оценке переноса на новые документы.}
\end{frame}
