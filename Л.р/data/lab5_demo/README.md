# Пример запуска Л.р. № 5

Файлы получены настоящим дообучением `Helsinki-NLP/opus-mt-en-ru` на корпусе
курса. Параметры, ревизия модели, версии библиотек, устройство и время запуска
зафиксированы в `manifest.json`. В наборе нет весов, состояний оптимизатора
или ручной разметки ошибок.

| Файл | Содержание |
|---|---|
| `split.csv` | принадлежность 160 сегментов к группам и частям |
| `predictions.csv` | 32 исходных и 32 адаптированных перевода, связанные с корпусом по `id` |
| `history.csv` | потери на обучении и проверке, включая исходную эпоху 0 |
| `summary.csv` | корпусные оценки трёх систем и число помеченных сегментов |
| `by_type.csv` | те же показатели по типам контента |
| `paired.csv` | попарное сравнение переводов с оригиналами и эталонами |

В ноутбуке режим `MODE = "saved"` читает исходные нейросетевые переводы и
кривые потерь. Поиск по памяти, технические проверки и метрики выполняются
заново. Проверяются контрольная сумма корпуса, состав частей и параметры.
Режим работает без PyTorch и сети после установки обычных зависимостей.

В этом запуске 96 пар использованы для обучения, 32 — для выбора эпохи,
32 — для тестирования. При пороге сходства 0,88 группировка не нашла близких
пар: все группы единичные. Работа алгоритма на вариантах шаблонов проверена
отдельными тестами. Первое подходящее разбиение выбирается по наличию типов
контента, чисел и подстановочных полей в оригиналах. Номер зерна записан
в описании запуска; качество переводов не участвует в выборе. Выбранная
по потерям эпоха указана в `manifest.json`.

Результат относится к данному разбиению и параметрам. Рост автоматических
оценок не заменяет ручную проверку и не доказывает улучшения на новом продукте.
Число флагов характеризует срабатывание эвристик, а не число всех ошибок:
смысл, стиль и терминология проверяются в самостоятельной части.
