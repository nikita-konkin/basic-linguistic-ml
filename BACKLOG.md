# Отложенные задачи

## Страница оценивания `/grading/` на сайте курса

Студентам нужно видеть, как оценивается работа, но
`Методические/Критерии_оценивания.md` целиком публиковать нельзя.

- Публиковать только разделы для студентов: «Принцип», «Шкала»,
  «Как выставляется каждый критерий», «Академическая честность».
- Разделы «Особые указания по работам» и «Об отрицательных результатах»
  **не публиковать**. В них, например, перечислены все пять дефектов
  задания 6 Л.р. № 3, то есть готовый ответ.
- Согласовать шкалу: критерии считаются из 100, а в журнале — одно число
  от 0 до 10 на работу. Либо на странице объяснить перевод, либо
  поменять одно из двух.
- Сборка: в `scripts/build_site.py` понадобится Markdown → HTML. Это первая
  сторонняя зависимость сборки (пакет `markdown`) — добавить её в
  `.github/workflows/site.yml`.
- Тест в `tests/test_site.py`: на странице нет особых указаний и номеров
  дефектов (`s002`, `s012`, `s028`, `s083`, `s115`). Сейчас тот же файл
  проверяет, что страницы оценивания нет вовсе (`test_no_grading_page_yet`) —
  этот тест заменить.
- Ссылка на страницу — в меню главной и в журнале.
