# Ветка `journal`

Здесь хранится только журнал группы для сайта курса —
`journal.json`, и только в зашифрованном виде. Кода курса в ветке нет.

Файл обновляется кнопкой «Сохранить» на странице
https://konkin-nikita.ru/basic-linguistic-ml/journal/ — руками его править
не нужно. Workflow «Сайт курса» в `main` берёт `journal.json` отсюда при
каждой сборке.

После каждого обновления журнала сайт пересобирается сам
(`.github/workflows/journal.yml`), группа видит изменения через 1–2 минуты.

Если «Сохранить» скачал файл (токен не задан), загрузите его сюда:
GitHub → ветка `journal` → Add file → Upload files. Имя может быть любым
вида `journal….json` — `journal-3.json`, `journal (1).json`: файл проверится
и сам станет `journal.json` (`.github/pick_journal.py`). Если загрузить не
журнал или два файла сразу, workflow остановится, а `journal.json` останется
прежним.

Внутри — шифротекст (AES-256-GCM): один блок открывается кодом группы,
другой паролем преподавателя. Без них прочитать ФИО и баллы нельзя. Как это
устроено и как создать токен для сохранения — в README ветки `main`, раздел
«Сайт курса».

Старые версии файла остаются в истории ветки и открываются тем кодом, который
действовал на момент сохранения.
